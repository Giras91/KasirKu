# Quick Cash

Quick Cash is a cashier app that is used through your Android phone / tablet and can print receipts via Bluetooth
<br/>
Aplikasi Kasir / POS untuk handphone android / tablet dengan print bluetooth - Versi Malaysia
<br/>
